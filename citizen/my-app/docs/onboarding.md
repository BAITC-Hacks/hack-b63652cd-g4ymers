# Гид первого входа

После авторизации житель автоматически видит 11 шагов: знакомство, навигация,
QR, геолокация, карточка места, описание, отправка, статусы, приватность,
баллы и помощь. Гид работает также при входе по прямой `/report/{qrCode}`
ссылке и не меняет текущий URL или заполненные поля.

«Назад» и «Далее» переключают шаги. «Позже», крестик или Escape сохраняют шаг
и закрывают гид. В «Помощи» доступны продолжение и повторное прохождение.
После «Завершить обучение» автоматический показ отключается.

Прогресс хранится в localStorage по ключу `citizen-onboarding:v2:<user UUID>`.
Это состояние конкретного аккаунта в конкретном браузере, не синхронизация
между устройствами. ИИН и токен в ключ не входят. Старый общий флаг
`citizen-onboarding-seen` не скрывает новый подробный гид. При недоступном
хранилище обучение работает до перезагрузки; после неё может появиться снова.

Гид не отправляет обращения и не вызывает камеру/GPS. Компонент геолокации
на страницах сканера и QR ждёт загрузки состояния гида и его закрытия.
Нижняя навигация телефона или верхняя навигация компьютера подсвечивается
через `data-tour`. Если нужного элемента нет на текущей странице либо экран
низкий, текстовая инструкция остаётся доступной без подсветки.

Контент: `lib/onboarding.ts`. Компоненты: `components/citizen/onboarding.tsx`.
Оформление: `app/onboarding.css`. Подключение — внутри авторизации,
с `key={user.id}`, поэтому аккаунты не наследуют шаги друг друга.

## Проверка

```sh
npm run lint
npm test
npm run build -- --webpack
```

Unit-тесты проверяют разделение аккаунтов, сохранение/возобновление,
завершение, повреждённое и недоступное хранилище, полноту шагов.
HTTP-тесты требуют отдельного запущенного тестового backend (см. backend/README).

В браузере: первый вход → шаг 1; «Далее» → обновление → тот же шаг;
Escape → «Помощь» → продолжение; последний шаг → завершение → обновление
без показа; повторный запуск → шаг 1. Проверить Tab/Shift+Tab, мобильный
экран 320/390 px и компьютер. Кнопки управления должны оставаться видимыми,
длинный текст — прокручиваться внутри карточки.
