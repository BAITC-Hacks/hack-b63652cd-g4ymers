# Аким на 5 часов

**Пять решений. Один бюджет. Видимые последствия для районов Астаны.**

Симулятор позволяет распределить 100 единиц бюджета и увидеть, как решения изменят качество жизни. Кабинет жителя собирает проблемы районов, общий Java API хранит обращения и сценарии в PostgreSQL.

- `akim/` — интерфейс акима с картой Астаны.
- `citizen/my-app/` — интерфейс жителя.
- `backend/` — Spring Boot API, авторизация, обращения, расчёт Score, PostgreSQL и миграции датасета.

В базе: 5 районов, 10 показателей, 14 мер из датасета хакатона. Базовый Score: **52.56**. Пример плана из задания: **56.54** при затратах **95/100**.

Запуск API, HTTP-контракт и проверки: [backend/README.md](backend/README.md).

Кабинет акима подключён к backend: вход, каталог, серверный Score, сохранённые сценарии и обработка обращений. Интерфейс жителя пока использует демонстрационные данные; его подключение к API ещё требуется. Данные хакатона синтетические, результаты показывают эффект в заданной модели.
